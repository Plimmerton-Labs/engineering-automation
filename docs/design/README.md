# Design

Design artefacts for this project: user journeys, trust flows, safety handling, onboarding, and service expectations — not only software architecture.

Per WORKFLOW.md, product-significant items require a design artefact before they can be marked `stage:ready`; design is a human-reviewed gate, not a formality. This directory is where that artefact lives.

No fixed structure is required. Organise by feature, issue, or initiative — whatever this project finds useful.
