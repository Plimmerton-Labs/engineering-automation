# Research

Research notes for this project: user research, market or competitive analysis, technical spikes, and other exploratory material that informs decisions before they're formalised.

This is exploratory material, not a decision record — significant decisions belong in [`docs/decisions/`](../decisions/) as ADRs once made. See WORKFLOW.md's "Design is first-class for product work" principle for how research and design feed into the Definition of Ready for product-significant work.

No fixed structure is required. Organise by topic, date, or issue — whatever this project finds useful.
