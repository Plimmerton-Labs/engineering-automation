# Contributing

Thank you for contributing to this project.

This repository follows the [Plimmerton Labs Engineering Playbook](https://github.com/Plimmerton-Labs/engineering-playbook). The short version:

- use the branch profile documented for this repository;
- for template or organisation-metadata repositories, open pull requests directly against `main`;
- for product repositories, branch from `develop` and open pull requests against `develop`, not `main`;
- keep changes small and reviewable;
- explain what changed, why, validation performed, assumptions, risks, and follow-up work;
- add or update ADRs for significant architecture, security, data, operational, or governance decisions;
- keep secrets out of source control and pull request discussion.
